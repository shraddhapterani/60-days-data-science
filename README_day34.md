# Day 34/60 – Business Intelligence Dashboards

## Objective

Build interactive customer analytics dashboards for business decision-making.

## Tools Used

* Python
* Pandas
* Plotly
* Jupyter Notebook

## Dashboard Features

* KPI cards for customer metrics
* Customer segmentation distribution
* Churn analysis
* Spending vs tenure visualization
* Churn by customer segment

## Key Insights

* Total customers: 300
* Churned customers: 74
* Churn rate: 24.7%
* Regular customers contribute the highest total spending.

## Files

* `day34_business_intelligence_dashboard.ipynb`
* `day34_segment_dashboard_report.csv`
* `day34_churn_dashboard_report.csv`

## Learning Outcome

Learned to create interactive dashboards and communicate customer analytics insights through business-friendly visualizations.
