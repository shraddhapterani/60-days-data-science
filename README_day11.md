# Day 11 – Machine Learning Foundations 🚀

## Objective
Built my first end-to-end Machine Learning workflow using the Superstore dataset.

## What I Did
- Selected features and target variable
- Split data into training and testing sets
- Used Linear Regression as a baseline model
- Trained the model on 7,840 records
- Generated predictions on 1,960 test records
- Evaluated the model using Mean Absolute Error (MAE)

## Features Used
- Shipping Days
- Order Year
- Category_Furniture
- Category_Office Supplies
- Category_Technology

## Target
- Sales

## Model
Linear Regression

## Result
- Training samples: 7,840
- Testing samples: 1,960
- MAE: 0.4381

## Prediction Output
The predictions were saved in:

`day11_predictions.csv`

## Key Learning
Machine Learning is a complete workflow:

**Data → Train/Test Split → Training → Prediction → Evaluation**

Building a simple baseline model is the first step toward developing better predictive models.
