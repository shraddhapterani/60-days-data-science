# Day 8: EDA Deep Dive - Superstore Sales

Explored customer segments, sub-category performance, shipping logistics, and 
feature correlations in the Superstore dataset.

## Key Findings
- Consumer segment generates the most revenue
- Phones and Chairs are top-performing sub-categories  
- Shipping durations align logically with Ship Mode selection
- No meaningful linear correlation between Sales, Shipping Duration, and Order Month
